# DailyProjects

One small project at a time, each one aimed at a real annoyance. Every project lives in its own folder with its own README and tests. `projects.json` is the running log.

| # | Project | What it does | Stack |
|---|---------|--------------|-------|
| 001 | [envcheck](envcheck) | Finds missing env vars by comparing `.env`, `.env.example` and your code | Python |
| 002 | [csv2xlsx](csv2xlsx) | Converts CSV to .xlsx, detecting encoding and delimiter so Excel stops guessing | Python |
| 003 | [sound-timer](sound-timer) | Practice timer that only counts the time you are actually making sound | JavaScript |
| 004 | [bankcsv](bankcsv) | Normalises bank CSV exports, tags spending by your rules, monthly summary | Python |
| 005 | [logfold](logfold) | Folds log lines that differ only by timestamps, ids and numbers into counted patterns | Go |
| 006 | [tzquick](tzquick) | Converts a typed phrase like "friday 5pm London in PT, Tokyo" between time zones, DST aware | JavaScript |
| 007 | [dirdiff](dirdiff) | Compares two folders by content and reports changed, moved and missing files | Rust |
| 008 | [drivecat](drivecat) | Catalogs unplugged drives so you can search and browse them without plugging them in | Python |
| 009 | [srtfix](srtfix) | Shifts, stretches or two-point syncs SRT subtitle timings and checks for overlaps | JavaScript |
| 010 | [awscron](awscron) | Validates AWS EventBridge cron and rate expressions and lists the next run times | JavaScript |
